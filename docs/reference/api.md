# API Reference

The website generates the API reference from
[`ateapi.proto`](../../api/ateapi/v1/ateapi.proto), which defines every
resource, method, message, and enum of the control-plane API along with its
documentation. Read the proto for the full reference. To change the reference,
edit its doc comments, following
[Documentation Comments](../api-style-guide.md#13-documentation-comments).
