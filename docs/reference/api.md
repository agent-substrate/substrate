# API Reference

The website generates the API reference from the ate-api-server gRPC API and the
Kubernetes CRD types. To change the reference, edit the doc comments in
[`ateapi.proto`](../../api/ateapi/v1/ateapi.proto) or in
[`api/infra/k8s/ate/v1`](../../api/infra/k8s/ate/v1), following
[Documentation Comments](../api-style-guide.md#13-documentation-comments).
