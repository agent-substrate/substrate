# The Agent Substrate Logo

This is Yolo the octopus, the logo and mascot of the Agent Substrate project.

Yolo is a friendly and intelligent octopus that represents the project's focus
on adaptability, intelligence, and versatility in building AI agents.

Yolo's 3 robot puppets are named:
  - b5d48c9b-f990-e499-ecd4-a691f086e4d4 (blue)
  - dd91bdd4-b583-a580-f69c-e4d4e19cad87 (yellow)
  - c29ca580-d69b-b198-f1b3-aba3e79baa93 (pink)

Yolo was designed and donated to the project by Nan Hockin.
