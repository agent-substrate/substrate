# Agent Substrate

> Agent Substrate is an open source, zero-trust runtime for running millions of stateful sandboxed agents on Kubernetes with sub-500ms suspend and resume.

Agent Substrate maps stateful **Actors** (addressed as `<atespace>/<actor>` and created from an `ActorTemplate`) onto smaller pools of pre-warmed **Workers** (Kubernetes Pods in a `WorkerPool`). Idle actors checkpoint their memory and filesystem state to object storage (GCS or S3) and release compute. When a request arrives with the `ate-target-actor: <atespace>/<actor>` header, `atenet-router` parks the request while `ate-api-server` assigns a ready worker, `atelet` streams the snapshot on the node, and `ateworker` restores the sandbox off the Kubernetes control-plane path.

Every actor runs inside a Cloud Hypervisor microVM or gVisor (`runsc`) sandbox. Plain Linux containers are unsupported. Actors hold zero ambient credentials inside the sandbox and start with default-deny networking. Outbound traffic traverses `atunnel` (authenticated with a short-lived per-actor SPIFFE X.509 certificate) to `atenet-egress`, which enforces `EgressPolicy` host allowlists and injects external credentials or actor JWTs out of band.

Substrate splits its APIs between cluster infrastructure and tenant workloads. Infrastructure resources (`WorkerPool`, `SandboxConfig`, `CSIDriverConfig` under `ate.dev/v1`) are Kubernetes CRDs reconciled by `atecontroller` and managed with `kubectl`. Workload and access resources (`Atespace`, `ActorTemplate`, `Actor`, `Tag`, `EgressPolicy`, `AccessPolicy`) live in PostgreSQL behind `ate-api-server`'s gRPC Control API (`api/ateapi/v1/ateapi.proto`) and are managed with `kubectl ate` or gRPC clients. Agent Substrate is a Cloud Native Computing Foundation sandbox project originally created by Google.
