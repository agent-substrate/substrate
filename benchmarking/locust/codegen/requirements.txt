# Build-time dependencies for generate.sh and for the nighthawk-ingress
# image's descriptor build. Kept apart from the load test's runtime
# requirements.txt so that generating the protos does not pull in locust, the
# opentelemetry exporters and google-cloud-storage.
#
# grpcio-tools bundles protoc along with the Python and gRPC codegen plugins.
# It is pinned because the generated files stamp the version that produced
# them ("Protobuf Python Version" in *_pb2.py, GRPC_GENERATED_VERSION in
# *_pb2_grpc.py), and the protobuf runtime refuses to load gencode newer than
# itself. When bumping this pin, keep the floors in ../requirements.txt and
# ../../nighthawk-ingress/requirements.txt at or above the versions the new
# gencode reports.
grpcio-tools==1.81.1
