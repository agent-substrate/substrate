Step 5 of 7
Configure WorkerPool Autoscaling (HPA & CapacityBuffer)
Configure horizontal pod autoscaling and standby capacity buffers so your agent fleet can absorb sudden traffic surges with instant (<100ms) cold starts.
💡 Tip: You can modify and re-apply the HPA and CapacityBuffer YAML manifests later at any time (e.g. manifests/workerpool-autoscaling.yaml).
📈 Standby Efficiency: 3 standby replicas absorb up to 300 bursty agent sessions with 0% CPU idle waste.
Select autoscaling option: Press 1-3
1 ⚡
Automatically configure HPA & CapacityBuffer with sensible defaults (Recommended)
Applies OneHPA (min=10, max=100) and fixed-replica-buffer (3 standby replicas) for instant <100ms agent session injection.
2 🛠️
Configure autoscaling manually via kubectl
Export template manifests to customize scaling metrics, CPU/memory thresholds, and buffer headroom.
3 ⏭️
Skip autoscaling configuration
Keep fixed worker pool replica count without horizontal dynamic scaling.
Applying autoscaling & capacity buffer...
Done
Autoscaling active! Now let's deploy the default Substrate WorkerPool.
Declarative Autoscaling & Buffer: manifests/workerpool-autoscaling.yaml
apiVersion: autoscaling.k8s.io/v2 kind: HorizontalPodAutoscaler metadata: name: workerpool-hpa namespace: substrate-system spec: scaleTargetRef: apiVersion: substrate.ate.dev/v1 kind: WorkerPool name: default-worker-pool minReplicas: 10 maxReplicas: 100 --- apiVersion: buffer.gke.io/v1 kind: CapacityBuffer metadata: name: standby-worker-buffer spec: standbyReplicas: 3

🤖 1. Get started by deploying your first actor session:
# Install the developer CLI curl -sSL https://ate.dev/atectl | sh # Deploy your first AI agent actor container from standard template atectl actor create my-first-actor \ --template=default-agent \ --workerpool=default-worker-pool # Send an interactive prompt to your running actor atectl actor execute my-first-actor \ --prompt="Analyze recent logs and report status"
📊 2. Inspect your standby workers at any time:
# Inspect live worker fleet status & standby buffers atectl get workerpools # Stream live data plane turn execution and pause/resume telemetry atectl logs workerpool/default-worker-pool --follow
